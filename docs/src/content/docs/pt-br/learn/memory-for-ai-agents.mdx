## Por que Agentes de Codificação com IA Precisam de Memória

Agentes de codificação com IA como Claude, Cursor e OpenCode são poderosos — mas têm uma limitação crítica: **sem memória entre sessões**.

Toda vez que você inicia uma nova sessão, seu agente:

- Esquece as decisões de arquitetura de ontem
- Não lembra das correções de bug que você descobriu
- Não consegue relembrar os padrões que sua equipe estabeleceu
- Precisa reaprender seu projeto do zero

Isso desperdiça tokens, gasta tempo e leva a repetições frustrantes.

## A Solução: Memória Persistente para Agentes de IA

O **toon-memory** dá ao seu agente de codificação com IA uma memória persistente que:

1. **Sobrevive a reinicializações** — a memória persiste entre sessões
2. **Funciona offline** — sem nuvem, sem chamadas de API, sem LLM necessário
3. **Economiza tokens** — 22% menos tokens que JSON
4. **Escala** — 80% menos chamadas de ferramenta por sessão
5. **Funciona em todo lugar** — mais de 15 agentes suportados

## O que os Agentes de IA Podem Lembrar?

### Decisões
```bash
memory_remember({
  category: "decision",
  key: "use-zod",
  content: "Use Zod for validation — simpler than Joi, better TS support"
})
```

### Correções de Bug
```bash
memory_remember({
  category: "bug",
  key: "redis-pool-fix",
  content: "Redis pool exhaustion — fix was max_connections=20"
})
```

### Padrões
```bash
memory_remember({
  category: "pattern",
  key: "api-versioning",
  content: "Always use /api/v1/ prefix for REST endpoints"
})
```

### Conhecimento
```bash
memory_remember({
  category: "knowledge",
  key: "deploy-process",
  content: "Deploy script lives in scripts/deploy.sh, runs on CI merge to main"
})
```

## Funcionalidades de Memória

- **27 ferramentas MCP** — remember, recall, forget, stats, summary, archive, diff, suggest, smart_recall, encrypt, decrypt e mais
- **Recall consciente de grafo** — conecta entradas relacionadas com links e referências
- **Pontuação de qualidade** — avalia automaticamente a qualidade da entrada (0-1)
- **Merge-dedup** — salva com a mesma chave, mescla automaticamente
- **TTL** — entradas podem expirar após 7d, 30d ou datas personalizadas
- **Criptografia** — AES-256-GCM para dados sensíveis
