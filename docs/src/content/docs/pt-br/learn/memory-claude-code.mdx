## Memória para Seu Agente IA Favorito

O **toon-memory** dá memória persistente aos agentes de codificação com IA que você já usa. Você prefira Claude Code, Cursor ou OpenCode, seu agente vai lembrar de tudo entre sessões.

## Configuração Específica por Agente

### Claude Code

Claude Code tem suporte completo a hooks com toon-memory:

```json
{
  "mcpServers": {
    "toon-memory": {
      "command": "npx",
      "args": ["-y", "toon-memory", "mcp"]
    }
  }
}
```

**Hooks:** SessionStart, PostToolUse, Stop — lembretes automáticos e carregamento de contexto.

### Cursor

Adicione a configuração MCP ao Cursor:

```json
{
  "servers": {
    "toon-memory": {
      "command": "npx",

  }
}
```

### OpenCode

Adicione em `.opencode/opencode.json`:

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

**Plugin:** `.opencode/plugins/toon-memory.ts` — Hooks SessionStart via plugin.

## Instalador Interativo (Mais Fácil)

```bash
npx toon-memory
```

O instalador irá:
1. Detectar quais agentes você tem instalados
2. Perguntar quais configurar
3. Adicionar a configuração MCP automaticamente

## O que Cada Agente Recebe

Todos os agentes recebem as mesmas **34 ferramentas MCP** e **4 recursos MCP**:

- `memory_remember` — Salvar decisões, padrões, bugs
- `memory_recall` — Buscar na memória (modo flat ou grafo)
- `memory_smart_recall` — Recall unificado com BM25 + grafo + qualidade
- `context_generate` — Briefing completo do projeto em uma chamada
- `context_diff` — O que mudou desde a última sessão
- E mais 20 ferramentas...

## Suporte Multi-Agente

Você pode configurar o toon-memory para **múltiplos agentes simultaneamente**:

```bash
npx toon-memory
# Selecione: claude, cursor, opencode
```

Todos os agentes compartilham o mesmo arquivo de memória em `.toon-memory/memory/data.toon`.

### Coordenação de Sessão

Ao executar múltiplos agentes em paralelo:

```bash
memory_sessions()
// 🧭 Sessões ativas (2):
// • claude @ feature/auth (você)
// • opencode @ feature/db
```

Veja quais arquivos outras sessões estão tocando para evitar conflitos.
