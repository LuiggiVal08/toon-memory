## Requisitos

- Node.js 20 ou superior
- npm, yarn ou pnpm

## Métodos de Instalação

### npm (Recomendado)

```bash
npm install -g toon-memory
```

### Scripts Standalone

#### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/LuiggiVal08/toon-memory/main/install.sh | sh
```

#### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/LuiggiVal08/toon-memory/main/install.ps1 | iex
```

### A partir do Código-Fonte

```bash
git clone https://github.com/LuiggiVal08/toon-memory.git
cd toon-memory
npm install
npm run build
npm link
```

## Verificar Instalação

```bash
toon-memory --version
# ou
npx toon-memory status
```

## Desinstalar

```bash
# Remover de todos os agentes
npx toon-memory uninstall

# Ou com instalação global
toon-memory uninstall
```
