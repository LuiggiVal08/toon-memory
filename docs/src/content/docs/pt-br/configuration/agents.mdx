## Configuração Automática

Execute o instalador interativo:

```bash
npx toon-memory
```

Isso irá:
1. Detectar agentes instalados
2. Configurar o servidor MCP para cada um
3. Criar o diretório de memória
4. Adicionar ao `.gitignore`
