## Comandos

```bash
npx toon-memory              # Instalador interativo (seleção de agente)
npx toon-memory init         # Configuração interativa com seleção de agente
npx toon-memory init --agent opencode       # Não-interativo: configurar agente específico
npx toon-memory init --agent opencode --agent claude  # Configurar múltiplos agentes
npx toon-memory init --agent opencode --scope global  # Configurar globalmente
npx toon-memory mcp          # Executar servidor MCP diretamente
npx toon-memory status       # Verificar status da instalação
npx toon-memory stats        # Visualizar estatísticas da memória
npx toon-memory export       # Exportar memória para JSON
npx toon-memory import <arquivo> # Importar memória de JSON
npx toon-memory watch [opções] # Backup automático com opções
npx toon-memory upgrade      # Atualizar para a versão mais recente
npx toon-memory uninstall    # Remover de todos os agentes
```

## Opções do Init

| Opção | Descrição | Padrão |
|-------|-----------|--------|
| `--agent <nome>` | Não-interativo: configurar agente(s) específico(s). Repita para múltiplos. | interativo |
| `--scope <escopo>` | `local` ou `global` — onde armazenar a configuração do agente | interativo |

## Opções do Watch

| Opção | Descrição | Padrão |
|-------|-----------|--------|
| `[intervalo]` | Intervalo de backup em minutos | 5 |
| `-c, --compress` | Ativar compressão gzip | desligado |
| `-l, --log [caminho]` | Ativar log em arquivo | desligado |
| `-m, --max-backups <n>` | Máximo de backups para manter (0=ilimitado) | 10 |

### Export

```bash
$ npx toon-memory export

Exported 45 entries to:
  /path/to/project/toon-memory-export.json
```

```bash
$ npx toon-memory import backup.json

```
