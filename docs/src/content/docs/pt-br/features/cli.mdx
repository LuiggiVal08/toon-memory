## Comandos

```bash
npx toon-memory              # Instalador interativo (seleção de agente)
npx toon-memory init         # Configuração interativa com seleção de agente
npx toon-memory init --agent opencode       # Não-interativo: configurar agente específico
npx toon-memory init --agent opencode --agent claude  # Configurar múltiplos agentes
npx toon-memory init --agent opencode --scope global  # Configurar globalmente
npx toon-memory mcp          # Executar servidor MCP diretamente
npx toon-memory status       # Verificar status da instalação
npx toon-memory stats        # Visualizar estatísticas da memória
npx toon-memory export       # Exportar memória para JSON
npx toon-memory import <arquivo> # Importar memória de JSON
npx toon-memory watch [opções] # Backup automático com opções
npx toon-memory upgrade      # Atualizar para a versão mais recente
npx toon-memory sleep        # Consolidação determinística (opcional)
npx toon-memory dense status # Status dos embeddings opcionais
npx toon-memory dense enable && npx toon-memory dense build
npx toon-memory dense install # Imprime o comando de instalação do embedder local
npx toon-memory uninstall    # Remover de todos os agentes
```

## Opções do Init

| Opção | Descrição | Padrão |
|-------|-----------|--------|
| `--agent <nome>` | Não-interativo: configurar agente(s) específico(s). Repita para múltiplos. | interativo |
| `--scope <escopo>` | `local` ou `global` — onde armazenar a configuração do agente | interativo |

## Opções do Watch

| Opção | Descrição | Padrão |
|-------|-----------|--------|
| `[intervalo]` | Intervalo de backup em minutos | 5 |
| `-c, --compress` | Ativar compressão gzip | desligado |
| `-l, --log [caminho]` | Ativar log em arquivo | desligado |
| `-m, --max-backups <n>` | Máximo de backups para manter (0=ilimitado) | 10 |

## Recuperação densa (opcional)

`dense status` mostra o modelo configurado, o caminho do módulo e o estado dos vetores. `dense enable` grava `config.dense.enabled = true`; `dense build` cria `vectors.bin` a partir das entradas atuais da memória.

Instale o embedder **localmente em cada projeto** onde o servidor MCP é executado:

```bash
npm install toon-memory-dense
npx toon-memory dense build
```

`npx toon-memory dense install` apenas imprime este comando. Defina `TOON_MEMORY_DENSE_MODULE=/caminho/absoluto/para/module.js` se o módulo não estiver no caminho de resolução padrão. Se o módulo ou o modelo estiver indisponível, o recall permanece apenas BM25.

## Consolidação ao final da sessão

`toon-memory sleep` promove de forma determinística as observações capturadas, reconstrói `edges.toon`, remove sinais expirados e deduplica entradas. Defina `config.sleep.enabled = true` ou `TOON_MEMORY_SLEEP=1` para executá-lo no `Stop` da sessão; é opcional.

### Stats

```bash
$ npx toon-memory stats

━━━━━━━━━━━━━━━━━━

├── pattern: 18
├── bug: 8
└── knowledge: 7

```

### Export

```bash
$ npx toon-memory export

🧠 toon-memory export

Exported 45 entries to:
  /path/to/project/toon-memory-export.json
```

### Import

```bash
$ npx toon-memory import backup.json

🧠 toon-memory import

Imported 3 new entries
Skipped 2 duplicates
```

### Watch
