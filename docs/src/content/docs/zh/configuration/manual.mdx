---
title: "手动 MCP 配置"
description: "手动 MCP 配置 — 将 toon-memory 添加到 Claude、Cursor、VS Code、Codex、Gemini 和 Zed 配置文件。分步设置指南。"
---

## OpenCode

### 项目级

添加到 `.opencode/opencode.json`：

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

### 全局

添加到 `~/.config/opencode/opencode.json`：

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```
