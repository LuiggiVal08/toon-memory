## Memoria para Tu Agente Favorito

**toon-memory** le da memoria persistente a los agentes de IA para coding que ya usas. Ya sea que prefieras Claude Code, Cursor u OpenCode, tu agente recordará todo entre sesiones.

## Configuración por Agente

### Claude Code

Claude Code tiene soporte completo de hooks con toon-memory:

```json
{
  "mcpServers": {
    "toon-memory": {
      "command": "npx",
      "args": ["-y", "toon-memory", "mcp"]
    }
  }
}
```

**Hooks:** SessionStart, PostToolUse, Stop — recordatorios automáticos y carga de contexto.

### Cursor

Agrega configuración MCP a Cursor:

```json
{
  "servers": {
    "toon-memory": {
      "command": "npx",
      "args": ["-y", "toon-memory", "mcp"]
    }
  }
}
```

### OpenCode

Agrega a `.opencode/opencode.json`:

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

**Plugin:** `.opencode/plugins/toon-memory.ts` — hooks SessionStart vía plugin.

## Instalador Interactivo (El Más Fácil)

```bash
npx toon-memory
```

El instalador:
1. Detecta qué agentes tienes instalados
2. Pregunta cuáles configurar
3. Agrega la configuración MCP automáticamente

## Qué Obtiene Cada Agente

Todos los agentes obtienen las mismas **35 herramientas MCP** y **4 recursos MCP**:

- `memory_remember` — Guardar decisiones, patrones, bugs
- `memory_recall` — Buscar memoria (modo flat o graph)
- `memory_smart_recall` — Recall unificado con BM25 + grafo + calidad
- `context_generate` — Resumen completo del proyecto en una llamada
- `context_diff` — Qué cambió desde la última sesión
- Y 20 herramientas más...

## Soporte Multi-Agente

Puedes configurar toon-memory para **múltiples agentes simultáneamente**:

```bash
npx toon-memory
# Seleccionar: claude, cursor, opencode
```

Todos los agentes comparten el mismo archivo de memoria en `.toon-memory/memory/data.toon`.

### Coordinación de Sesiones

Cuando ejecutas múltiples agentes en paralelo:

```bash
memory_sessions()
// 🧭 Sesiones activas (2):
// • claude @ feature/auth (tú)
// • opencode @ feature/db
```

Mira qué archivos están tocando otras sesiones para evitar conflictos.
