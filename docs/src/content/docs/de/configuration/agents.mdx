## Auto-Setup

Starte den interaktiven Installer:

```bash
npx toon-memory
```

Dies wird:
1. Installierte Agenten erkennen
2. Den MCP-Server für jeden konfigurieren
3. Das Speicherverzeichnis anlegen
4. Zur `.gitignore` hinzufügen
