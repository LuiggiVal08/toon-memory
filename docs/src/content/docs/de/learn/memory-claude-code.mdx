## Speicher für deinen Lieblings-AI-Agenten

**toon-memory** gibt persistenen Speicher an die AI-Coding-Agenten, die du bereits verwendest. Egal ob du Claude Code, Cursor oder OpenCode bevorzugst — dein Agent wird sich an alles zwischen Sitzungen erinnern.

## Agentspezifische Einrichtung

### Claude Code

Claude Code hat volle Hook-Unterstützung mit toon-memory:

```json
{
  "mcpServers": {
    "toon-memory": {
      "command": "npx",
      "args": ["-y", "toon-memory", "mcp"]
    }
  }
}
```

**Hooks:** SessionStart, PostToolUse, Stop — automatische Erinnerungen und Kontext-Laden.

### Cursor

### OpenCode

Zu `.opencode/opencode.json` hinzufügen:

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

**Plugin:** `.opencode/plugins/toon-memory.ts` — SessionStart-Hooks über Plugin.

## Interaktiver Installer (Am einfachsten)

```bash
npx toon-memory
```

Der Installer wird:
1. Erkennen, welche Agenten installiert sind
2. Fragen, welche konfiguriert werden sollen
3. MCP-Konfiguration automatisch hinzufügen

## Was jeder Agent erhält

Alle Agenten erhalten dieselben **37 MCP-Tools** und **4 MCP-Ressourcen**:

- `memory_remember` — Entscheidungen, Muster, Bugs speichern
- `memory_recall` — Speicher durchsuchen (flach oder Graph-Modus)
- `memory_smart_recall` — Einheitlicher Abruf mit BM25 + Graph + Qualität
- `context_generate` — Vollständiges Projekt-Briefing in einem Aufruf
- `context_diff` — Was sich seit letzter Sitzung geändert hat
- Und 20 weitere Tools...

## Multi-Agent-Unterstützung

Du kannst toon-memory für **mehrere Agenten gleichzeitig** konfigurieren:

```bash
npx toon-memory
# Auswählen: claude, cursor, opencode
```

Alle Agenten teilen sich dieselbe Speicherdatei unter `.toon-memory/memory/data.toon`.

### Sitzungs-Koordination

Bei paralleler Ausführung mehrerer Agenten:

```bash
memory_sessions()
// 🧭 Aktive Sitzungen (2):
// • claude @ feature/auth (du)
// • opencode @ feature/db
```

Sieh, welche Dateien andere Sitzungen bearbeiten, um Konflikte zu vermeiden.
