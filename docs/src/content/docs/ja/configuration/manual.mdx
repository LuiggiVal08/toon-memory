title: "手動MCP設定"
description: "手動MCP設定 — toon-memoryをClaude、Cursor、VS Code、Codex、Gemini、Zedの設定ファイルに追加。ステップバイステップのセットアップガイド。"
---

## OpenCode

### プロジェクトレベル

`.opencode/opencode.json`に追加：

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

### グローバル

`~/.config/opencode/opencode.json`に追加：

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```
