## 自動セットアップ

インタラクティブインストーラーを実行します：

```bash
npx toon-memory
```

これにより：
1. インストール済みのエージェントを検出
2. 各エージェントのMCPサーバーを設定
3. メモリディレクトリを作成
4. `.gitignore`に追加

## 手動セットアップ

エージェント別の手順は[手動設定](/toon-memory/ja/configuration/manual)を参照してください。
