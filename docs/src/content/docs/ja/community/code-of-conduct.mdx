## 私たちの誓い

私たちは、メンバー、コントリビューター、リーダーとして、年齢、体型、外見上または内見上の障害、民族、性の特徴、性自認と表現、経験のレベル、教育、社会経済的地位、国籍、外見、人種、宗教、または性的同一性と指向に関わらず、すべての人にとってハラスメントのない参加を約束します。

## 私たちの基準

ポジティブな環境に貢献する行動の例：

- 歓迎的で包括的な言葉を使用する
- 異なる視点と経験を尊重する
- 建設的な批判を丁寧に受け入れる
- コミュニティにとって最善のこと focusing on
- 他のコミュニティメンバーへの共感を示す

許容できない行動の例：

- セクシャルな言葉や画像の使用、およびあらゆる種類のセクシャルな注意やアプローチ
- トローリング、侮辱的または軽蔑的なコメント、個人的または政治的な攻撃
- 公的または私的なハラスメント
- 明示的な同意なく、物理的またはメールアドレスなどの個人情報を公開する
- 専門的な場所で不適切と合理的に考えられるその他の行為

## 執行

虐待的、ハラスメント、またはその他の許容できない行動のインスタンスは、https://github.com/LuiggiVal08/toon-memory/issues で執行を担当するコミュニティリーダーに報告できます。

すべての苦情は迅速かつ公正に審査・調査されます。
