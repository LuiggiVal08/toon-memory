## Pourquoi comparer les solutions de mémoire IA ?

Les agents de codage IA ont besoin de mémoire pour être productifs. Mais quelle solution mémoire est la meilleure ? Ce guide compare les trois options leaders :

- **toon-memory** — Serveur MCP avec format économe en tokens
- **mem0** — Plateforme de mémoire cloud
- **shodh-memory** — Mémoire hybride vectorielle + graphe

## Analyse approfondie : toon-memory

### Points forts

- **Efficacité des tokens** — Le format TOON utilise 22% de tokens en moins que le JSON
- **Rappel conscient du graphe** — BM25 + centralité + scoring de qualité
- **Support des agents** — 15+ agents avec configuration automatique
- **Zéro dépendance** — pas de cloud, pas de Docker, pas de sentence-transformers
- **Ensemble complet de fonctionnalités** — 34 outils MCP, chiffrement, coordination multi-sessions

### Points faibles

- **Pas de recherche vectorielle** — utilise BM25, pas d'embeddings
- **MCP requis** — l'agent doit supporter le Model Context Protocol
- **Local uniquement** — pas de synchronisation cloud entre machines (utilisez Git à la place)

### Idéal pour

- Les développeurs qui souhaitent une **mémoire hors ligne et privée**
- Les équipes utilisant **plusieurs agents IA** (Claude, Cursor, OpenCode)
- Les projets où **l'efficacité des tokens** compte (économies de coûts)

## Analyse approfondie : mem0

### Points forts

- **Service géré** — aucune configuration nécessaire
- **Recherche vectorielle** — similarité sémantique avec embeddings
- **Synchronisation cloud** — fonctionne entre machines automatiquement
- **Accès API** — intégration facile

### Points faibles

- **Internet requis** — pas de support hors ligne
- **Coût** — tarification basée sur l'usage s'accumule
- **Confidentialité** — les données quittent votre machine
- **Pas d'optimisation tokens** — pas conçu pour l'efficacité LLM
- **Fonctionnalités limitées** — pas de scoring de qualité, pas de rappel graphe

### Idéal pour

- Les équipes ayant besoin de **synchronisation inter-machines** sans Git
- Les projets où **la confidentialité n'est pas une préoccupation**
- Prototypage rapide sans configuration locale

## Analyse approfondie : shodh-memory

### Points forts

- **Recherche hybride** — rappel vectoriel + graphe
- **Score de qualité** — algorithme BND
- **Hors ligne** — pas de cloud nécessaire
- **Stockage RocksDB** — rapide, persistant

### Points faibles

- **Configuration complexe** — nécessite Docker + sentence-transformers
- **Dépendances lourdes** — environnement Python volumineux
- **Claude uniquement** — support d'agents limité
- **Pas d'optimisation tokens** — pas conçu pour l'efficacité LLM

### Idéal pour

- Les projets nécessitant **recherche vectorielle + rappel graphe**
- Les équipes utilisant déjà **Docker** et **Python**
- Les environnements Claude uniquement
