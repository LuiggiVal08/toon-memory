title: "Configuration MCP manuelle"
description: "Configuration MCP manuelle — ajoutez toon-memory aux fichiers de config de Claude, Cursor, VS Code, Codex, Gemini et Zed. Guide d'installation étape par étape."
---

## OpenCode

### Au niveau du projet

Ajoutez à `.opencode/opencode.json` :

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```

### Global

Ajoutez à `~/.config/opencode/opencode.json` :

```json
{
  "mcp": {
    "toon-memory": {
      "type": "local",
      "command": ["npx", "-y", "toon-memory", "mcp"],
      "enabled": true
    }
  }
}
```
