## Configuration automatique

Lancez l'installateur interactif :

```bash
npx toon-memory
```

Cela va :
1. Détecter les agents installés
2. Configurer le serveur MCP pour chacun
3. Créer le répertoire mémoire
4. Ajouter à `.gitignore`
