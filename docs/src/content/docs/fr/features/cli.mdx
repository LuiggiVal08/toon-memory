## Commandes

```bash
npx toon-memory              # Installateur interactif (sélection d'agent)
npx toon-memory init         # Configuration interactive avec sélection d'agent
npx toon-memory init --agent opencode       # Non-interactif : configurer un agent spécifique
npx toon-memory init --agent opencode --agent claude  # Configurer plusieurs agents
npx toon-memory init --agent opencode --scope global  # Configurer globalement
npx toon-memory mcp          # Lancer le serveur MCP directement
npx toon-memory status       # Vérifier l'état de l'installation
npx toon-memory stats        # Voir les statistiques mémoire
npx toon-memory export       # Exporter la mémoire en JSON
npx toon-memory import <file> # Importer la mémoire depuis un JSON
npx toon-memory watch [opts] # Sauvegarde automatique avec options
npx toon-memory upgrade      # Mettre à jour vers la dernière version
npx toon-memory sleep        # Consolidation déterministe (optionnelle)
npx toon-memory dense status # État des embeddings optionnels
npx toon-memory dense install --yes && npx toon-memory dense enable --build
npx toon-memory dense install # Installe l'embedder local après confirmation
npx toon-memory uninstall    # Supprimer de tous les agents
```

## Options d'init

| Option | Description | Défaut |
|--------|-------------|--------|
| `--agent <name>` | Non-interactif : configurer un ou plusieurs agents. Répéter pour plusieurs. | interactif |
| `--scope <scope>` | `local` ou `global` — où stocker la config de l'agent | interactif |

## Options de watch

| Option | Description | Défaut |
|--------|-------------|--------|
| `[interval]` | Intervalle de sauvegarde en minutes | 5 |
| `-c, --compress` | Activer la compression gzip | désactivé |
| `-l, --log [path]` | Activer la journalisation fichier | désactivé |
| `-m, --max-backups <n>` | Nombre max de sauvegardes à conserver (0=illimité) | 10 |

## Recherche dense (optionnelle)

`dense status` affiche le modèle configuré, la résolution du module, le nombre de vecteurs, les vecteurs obsolètes et les erreurs de chargement. `dense enable --build` active Dense et crée `vectors.bin` de façon incrémentale à partir des entrées actuelles.

Installez l'embedder **localement dans chaque projet** où le serveur MCP s'exécute :

```bash
npx toon-memory dense install --yes
npx toon-memory dense enable --build
```

`npx toon-memory dense install` installe l'embedder localement après confirmation ; `--dry-run` n'affiche que la commande. Le premier build télécharge le modèle dans un cache local. Définissez `TOON_MEMORY_DENSE_MODULE=/chemin/absolu/vers/module.js` si le module n'est pas dans le chemin de résolution par défaut. Si le module ou le modèle est indisponible, le rappel reste limité à BM25. L'embedder apporte des dépendances natives transitives : épinglez les versions et vérifiez les scripts d'installation dans les environnements restreints.

## Consolidation en fin de session

`toon-memory sleep` promeut de façon déterministe les observations capturées, reconstruit `edges.toon`, élagne les signaux expirés et déduplique les entrées. Définissez `config.sleep.enabled = true` ou `TOON_MEMORY_SLEEP=1` pour l'exécuter lors du `Stop` de la session ; c'est optionnel.

## Exemples

### Stats

```bash
$ npx toon-memory stats

🧠 toon-memory stats

📊 Memory Stats
━━━━━━━━━━━━━━━━━━
Total entries: 45
├── decision: 12
├── pattern: 18
├── bug: 8
└── knowledge: 7
Last updated: 2026-07-10
File size: 12.4 KB
```

### Export

```bash
$ npx toon-memory export

🧠 toon-memory export

Exported 45 entries to:
  /path/to/project/toon-memory-export.json
```

### Import

```bash
$ npx toon-memory import backup.json

🧠 toon-memory import

Imported 3 new entries
Skipped 2 duplicates
```

### Watch

```bash
$ npx toon-memory watch 15 -c -m 20

🧠 toon-memory watch

Watching memory file every 15 minutes...
Max backups: 20
Compression: enabled
Logging: disabled
Press Ctrl+C to stop

📦 Backup #1 created: 2026-07-11T16-00-00-000Z
📦 Backup #2 created: 2026-07-11T16-15-00-00-000Z
^C
✅ Watch stopped. 2 backups created.
```
