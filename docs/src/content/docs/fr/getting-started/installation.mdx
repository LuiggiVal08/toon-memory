## Prérequis

- Node.js 20 ou supérieur
- npm, yarn ou pnpm

## Méthodes d'installation

### npm (Recommandé)

```bash
npm install -g toon-memory
```

### Scripts autonomes

#### macOS / Linux

```bash
curl -fsSL https://raw.githubusercontent.com/LuiggiVal08/toon-memory/main/install.sh | sh
```

#### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/LuiggiVal08/toon-memory/main/install.ps1 | iex
```

### Depuis les sources

```bash
git clone https://github.com/LuiggiVal08/toon-memory.git
cd toon-memory
npm install
npm run build
npm link
```

## Vérifier l'installation

```bash
toon-memory --version
# ou
npx toon-memory status
```

## Désinstallation

```bash
# Supprimer de tous les agents
npx toon-memory uninstall

# Ou avec l'installation globale
toon-memory uninstall
```
