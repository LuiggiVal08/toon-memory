## 자동 설정

대화형 설치 프로그램을 실행합니다:

```bash
npx toon-memory
```

이것은 다음을 수행합니다:
1. 설치된 에이전트를 감지합니다
2. 각각의 MCP 서버를 설정합니다
3. 메모리 디렉토리를 생성합니다
4. `.gitignore`에 추가합니다

## 수동 설정
